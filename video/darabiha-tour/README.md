# Darabiha product tour

A 29-second, 1920×1080 Remotion tour of the family archive.

The source captures contain private family information and are intentionally
excluded from Git. Place the following screenshots in `public/captures/` before
rendering: `family.png`, `tree.png`, `profile.png`, `list.png`, `timeline.png`,
`calendar.png`, `map.png`, and `numbers.png`.

```sh
npm install
npm run studio
npm run render
```

The rendered video is written to `out/darabiha-tour.mp4` and is also excluded
from Git.
