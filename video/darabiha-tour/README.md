# Darabiha product tour

A 14-second, 1920×1080 Remotion tour of the family archive, centered on live
tree panning and zooming.

The source captures contain private family information and are intentionally
excluded from Git. Place `tree-motion.mov` and `profile.png` in
`public/captures/` before rendering.

```sh
npm install
npm run studio
npm run render
```

The rendered video is written to `out/darabiha-tour.mp4` and is also excluded
from Git.
